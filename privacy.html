28 Days: Privacy and Terms of Use

Classroom Edition, at learn28days.org. Last updated November 17, 2026.

In short
  • The game collects no personal information from students or anyone else.
  • No accounts, no names, no email addresses, no cookies, no ads.
  • Game progress is saved only in the browser on the device being used.
  • Visits are counted anonymously so the creator can see how often the game is used.
  • It's free to use in classrooms.

Privacy

What the game collects

Nothing personal. Students never type their name or any information about themselves, and there is no sign-up or login. The game doesn't use cookies, advertising, or social media trackers.

Saved progress

The game saves a student's progress at the start of each in-game day, using the browser's local storage on that device. This save never leaves the device and is never sent to anyone. Clearing the browser's site data deletes it. On a shared computer, the next student can start fresh from the title screen.

Anonymous visit counting

The site uses GoatCounter, a privacy-focused counter, to see how many times pages are visited and how often the game is started and finished. According to GoatCounter's privacy policy:

  • It stores totals such as which page was visited, the referring website, browser and operating system, language, screen width, and an approximate location (country or region) worked out from the IP address.
  • It doesn't store IP addresses, the full browser identifier, or any tracking ID.
  • To avoid counting the same visitor twice, it keeps a short-lived link between a visitor and a random ID in memory for up to 8 hours. This isn't saved.
  • It doesn't store anything in the visitor's browser: no cookies, no local storage.

If a school network blocks the counter, the game works exactly the same.

Website hosting

The site is hosted by Vercel. Like any web host, Vercel's servers handle each visitor's IP address in order to deliver the pages, and keep server logs to operate and secure its service. See Vercel's privacy policy. Everything else the game needs, including its font, is served from this site; no other outside services are used.

Children

28 Days is made for middle school students. Because it collects no personal information from anyone, it collects none from children.

Not medical advice

28 Days teaches general health information. It isn't medical advice and doesn't replace a doctor or school nurse. Students with questions about their own bodies should talk to a parent or guardian, the school nurse, or a doctor.

Accuracy

Every health fact in the game was checked against pages from the CDC, ACOG, NIH and others, and each one shows its source. The full list is in the fact check. The game hasn't yet been reviewed by a medical professional, and it is provided as is. If you find a mistake, please email swarapala@gmail.com so it can be fixed.
